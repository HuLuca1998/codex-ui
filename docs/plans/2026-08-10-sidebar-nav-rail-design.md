# 左侧菜单式导航与可折叠布局设计

## 背景

侧栏原本把三件事塞进同一列：顶部「会话 / 报表 / GitHub」三个 tab、下面一排「全部 / Codex / Claude」来源过滤，再往下才是搜索、日期过滤和会话列表。
问题有三个：

- 视图切换和来源过滤是两套控件，但用户心里只有一件事——「我现在要看哪一摊」。
- 报表和 GitHub 是全幅视图，却仍旧占着一条 272px 的会话列表栏，主区被白白挤窄。
- 侧栏无法收起，窄屏下对话区可用宽度不足。

## 目标

- 左侧变成菜单：报表 / GitHub / Codex / Claude 四项，互斥单选。
- 菜单可折叠，折叠后只剩图标。
- Codex / Claude 菜单下保持左右分栏：左会话列表，右对话区。
- 报表 / GitHub 是全幅视图，会话列表整条收起。

## 布局

三段式，从左到右：

```
#sidebar
├── #rail    菜单栏，展开 184px / 折叠 64px
└── aside    会话列表，宽度 --sbw（拖拽调整），全幅视图下 display:none
#sbResize    列表拖拽条，跟随 aside 显隐
main         对话区 / 报表 / GitHub
```

`#rail` 与 `aside` 包在 `#sidebar` 里，是为了移动端能把「菜单栏 + 会话列表」作为一个整体滑出抽屉，
抽屉相关 CSS 只需换一个选择器，不必分别摆放两个 fixed 元素。

折叠状态挂在 `body.rail-collapsed`，全幅视图挂在 `body.view-full`，
两者都只切换 class，具体收起哪些元素由 CSS 决定，JS 不碰布局细节。

## 视图状态机

`setView(v)`，`v ∈ {report, github, codex, claude}`：

- `codex` / `claude`：会话视图。**来源过滤由菜单锁定**（`srcFilter = v`），
  Claude 额外放出项目下拉；列表标题随之切换。
- `report` / `github`：全幅视图。加 `body.view-full`，隐藏 composer 与会话列表。

原来的 `srcFilter="all"`（Codex + Claude 混排）随三个来源 pill 一起删除——
菜单已经把来源表达成互斥的两个入口，再留一个「全部」等于把刚拆开的两件事又粘回去。
`sidebarView` 沿用旧变量名，取值改为上述四种，判断会话视图统一走 `isListView()`。

选中的菜单存 `localStorage.codexui.view`，折叠状态存 `codexui.railCollapsed`，下次启动直接恢复。
启动时预选最近会话会把视图拉到该会话所属菜单，因此若恢复的是报表 / GitHub，选完会话后再切回去。

`window.openSession()`（菜单栏「活跃会话」跳转用）按会话 `source` 决定落到哪个菜单，
否则目标会话会被来源过滤挡在列表外，跳转看起来像没反应。

## 常驻操作

「+ 新任务」「分享」「设置」原本在会话列表底部，全幅视图下会跟着列表一起消失，
所以移到菜单栏底部常驻；折叠时收成一列图标。「实时监听中」指示留在会话列表底部，它描述的就是列表本身。

菜单项右侧显示当前日期范围内该来源的会话数，数据来自 `renderList()` 已有的遍历，不额外请求。

## 移动端

抽屉宽度从 332px 提到 368px：里面要同时放 64px 菜单栏和会话列表。
菜单栏在抽屉里恒定窄栏（无视 `rail-collapsed`），折叠按钮隐藏——抽屉本身就是折叠。
报表 / GitHub 视图下会话列表为空，菜单栏铺满抽屉并恢复文字标签，避免右侧大片空白。

## 验证

`./build-mac.sh` 通过后，用 headless Chrome 对本机服务截图核对四种状态：
桌面展开、桌面折叠、桌面报表全幅、移动端抽屉（会话视图 / 报表视图）。
